# Glimmer-1-Base: прямое редактирование весов обычной языковой модели

Модель общего назначения с **11 856** независимыми параметрами, обученная автором на FineWeb-Edu. Это другой эксперимент, чем сложение первого трансформера. Архитектура: Llama, 2 слоя, hidden 16, 4 query-головы и 1 KV-голова, SwiGLU 24, RoPE, связанный embedding/readout 512×16. Веса оригинала проверены по SHA-256; источник и revision — `sources.json`.

Собственный baseline: 547/1024 (53,42%) diagnostic и 1052/2048 (51,37%) validation на заранее выбранном поднаборе BLiMP. Итоговые отложенные результаты после фиксации правки — `REPORT.md`. Не отождествлять наши результаты с 52,43% полного BLiMP в карточке автора.

## Чистое воспроизведение

В новой папке разместите наши `.py`, `tests`, `sources.json`, `requirements.txt`. Не переносите старые protocol, freeze, results и checkpoints, чтобы заново воспроизвести полный цикл:

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python fetch_sources.py
.venv/bin/python experiment.py baseline
.venv/bin/python diagnose.py
.venv/bin/python propose_edits.py
.venv/bin/python experiment.py finalize
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python make_paper_artifacts.py
```

Стадия одной явной правки: `python experiment.py edit --spec hypotheses/edit_01.json`. Не смешивать её с полным `propose_edits.py`: бюджет общий, максимум 12 полных оценок validation. Редактирование запрещено после появления `freeze.json`. Повторный `python experiment.py report` работает только с уже сохранёнными результатами.

## Бенчмарк

Выбраны восемь разделов BLiMP по лингвистическому разнообразию до запуска модели: местоименное согласование, определитель/существительное, регулярное и нерегулярное субъектно-глагольное согласование, принцип A, NPI, wh/that и нерегулярные причастия. Из каждого берутся 128 диагностических и 256 validation-пар; остальные уникальные пары идут в test. Точные размеры и удалённые дубликаты — в `protocol.json`. Любое точное повторение предложения исключается глобально, включая внутри одного split. Сохраняются общие грамматические шаблоны и словарь: это не тест на невиданные лингвистические конструкции.

Основная метрика — стандартное предпочтение минимальной пары по суммарной авторегрессионной лог-вероятности предложения. Правильное предложение должно иметь строго большую вероятность, ничья — ошибка. BOS задаёт контекст; EOS не оценивается; нормализации по длине нет. Это teacher-forced likelihood scoring, стандартный для BLiMP, **а не свободное решение арифметики или генерация ответа**. Пять свободных жадных продолжений сохраняются отдельно как иллюстрации и не входят в критерий выбора.

Исходный test считается отдельным процессом в `sealed_final/baseline` и не открывается до фиксации весов, edit_spec и кода. После выбора правки — три случайных контроля с той же маской и L2-нормой, фиксированные seeds, парный стратифицированный bootstrap, 20 000 реплик, 95% интервал. Результаты каждой грамматической категории приводятся отдельно. Интервал относится к фиксированной правке и выбранным примерам, а не к независимым обучениям и другим моделям.

Длина BPE-последовательности сильно влияет на raw likelihood. Анализ по одинаковой/разной длине обязателен для интерпретации. Правка общей финальной RMSNorm может менять калибровку вероятностей и оценку BLiMP, сохраняя argmax генерации; такое изменение не называется новым знанием грамматики. Предварительные гипотезы, все попытки и ограничения сохраняются.
