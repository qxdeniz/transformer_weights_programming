# Статус пилота: Calculator LLM

Проверен опубликованный checkpoint на 104 740 параметров. До экспериментальных правок обнаружена ошибка токенизатора веб-демо: замена `x` портит `six`/`sixty`. Использован исходный токенизатор автора из кода обучения, что является исправлением совместимости до baseline, а не улучшением весов.

На diagnostic 434/434 и validation 868/868 ответы правильны. Из-за потолка 100% гипотеза исправления ошибок не сформирована, экспериментальные веса не редактировались и улучшение не заявляется. Сохранённые финальные baseline-прогнозы остаются закрытыми; этот пилот не включается в подтверждающее сравнение изменённых моделей.

По следующему указанию пользователя основная вторая попытка перенесена на обычную языковую модель Glimmer-1-Base. Пилот сохранён для прозрачности выбора объекта. Исходный код автора допускает включение всей конечной области в обучение, поэтому наши splits не доказывают отсутствие задач в первоначальном обучении.
